# 16화. 최후의 검토

반려 버튼 위에서 멈춰 있던 손가락 끝에 맺힌 미세한 땀방울이 액정 화면의 정전식 센서 위로 미끄러져 내렸다. 화면의 가장자리가 미세하게 떨리며 자극을 감지했다. 이 버튼 하나를 누르면 내 이중 신분의 증거를 기각하고 부당함을 소명할 수 있는 기회라도 얻을 수 있을 터였다. 하지만 그 뒤에 도사린 시스템의 덫은 너무나 명확했다.

나는 굳어버린 손가락을 잠시 거두고, 스마트폰 상단 바를 쓸어 내려 네트워크 설정 아이콘을 바라보았다. 와이파이와 모바일 데이터 연결을 강제로 차단한다면 어떨까. 네트워크가 끊긴 오프라인 상태에서 반려 버튼을 누르고 소명 절차를 우회한다면, 기기 식별자나 IP 주소가 실시간으로 원청 데이터베이스와 대조되는 것을 막을 수 있지 않을까 하는 실낱같은 생각이 스쳤다.

손가락이 상단 바의 와이파이 버튼을 툭 내리쳤다.

즉시 화면 전체가 짙은 회색빛으로 물들며 강한 진동이 울렸다. 플랫폼 앱은 내가 단절을 시도한 찰나를 놓치지 않고 거대한 경고 팝업을 화면 한가운데 밀어 올렸다.

[보안 경고: 네트워크 연결 단절 감지]
- 승인자 계정(user_9931)의 작업 단말기에서 비정상적인 네트워크 차단 상태가 확인되었습니다.
- 플랫폼 이용 약관 제24조에 따라, 검토 작업 중 임의의 통신 차단 및 우회 시도는 시스템 보안 위협 및 기밀 탈취 시도로 간주됩니다.
- 본 경고 발생 후 10초 이내에 네트워크를 복구하지 않을 경우, 해당 계정은 즉시 영구 동결되며 당월 발생한 모든 미정산 수수료(1,200원) 및 정산 대금이 전액 몰수됩니다.

화면 하단에는 10초부터 시작되는 붉은색 카운트다운 숫자가 뚝뚝 떨어지며 붉은 테두리를 깜빡였다. 9, 8, 7...

퇴로는 없었다. 기계는 인간의 도피처와 우회로까지 완벽하게 계산하여 철창의 간격을 좁혀놓고 있었다. 네트워크를 끊는 순간 나는 내 손으로 지난 한 달간의 모든 노동 대가를 공중으로 날려버리게 된다. 월세 삼십만 원을 내지 못해 이 눅눅한 지하 방에서 쫓겨나는 미래가 카운트다운의 숫자와 함께 선명하게 다가왔다.

시간이 없었다. 3, 2, 1...

나는 떨리는 손으로 다시 와이파이 버튼을 눌러 네트워크를 복구했다. 화면이 새로고침되며 원상태로 돌아왔고, 팝업창 뒤로 다섯 번째 문서인 내 용역 계약 해지 통지서가 다시 매끄럽게 모습을 드러냈다.

반려를 누르면 이중 노동 자백으로 영구 동결과 소송. 네트워크를 끊으면 미정산금 몰수와 즉각 퇴거. 남은 선택지는 오직 하나뿐이었다.

내 손가락은 스스로의 의지와는 상관없이 천천히, 그러나 무겁게 움직여 화면 우측 하단의 붉은색 [승인] 버튼 위로 올라갔다. 

터치 패널이 따뜻한 체온을 인식하고 미세한 진동을 울렸다. 

[문서 WRK-2026-10043 최종 승인이 완료되었습니다.]

화면 우측 상단에 고정되어 있던 숫자가 미끄러지듯 변했다.

[누적 수수료: 1,500원]

삼백 원이 늘어났다. 내 해고를 보증하고, 내 계정을 파멸시키며 얻어낸 정확히 삼백 원의 대가가 가상의 지갑 속으로 얹어졌다. 그 비참한 숫자가 화면 위에서 깜빡이는 순간, 스마트폰이 짧게 울어대며 문자 메시지 수신 알림을 띄웠다.
